### Template 1: EA Anywhere — ขอข้อมูลสถานีชาร์จ

**Subject:** ขอความร่วมมือด้านข้อมูลสถานีชาร์จ — EV Charge Map Thailand

สวัสดีครับ/ค่ะ ทีม EA Anywhere

ผม/ดิฉัน [ชื่อ] จาก EV Charge Map Thailand (evchargemap.th) 
แพลตฟอร์มแผนที่จุดชาร์จรถ EV ที่ครอบคลุมทั่วประเทศไทย

**เราต้องการ:**
- ข้อมูลสถานีชาร์จ EA Anywhere ทั้งหมด (พิกัด, จำนวนหัวชาร์จ, กำลังไฟ, เวลาเปิด-ปิด)
- API สำหรับดึงสถานะ real-time (ว่าง/ไม่ว่าง)

**ประโยชน์ที่ EA จะได้รับ:**
- ผู้ใช้งาน 10,000+ คน/เดือน เห็นข้อมูลสถานี EA โดยตรง
- Link กลับมายัง EA app จากทุกสถานีในแผนที่
- Badge "EA Anywhere" บนแผนที่ที่คนใช้วางแผนเส้นทาง

ขอนัดประชุม 30 นาทีเพื่อหารือเพิ่มเติมได้ไหมครับ/ค่ะ?
